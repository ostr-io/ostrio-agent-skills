# CLAUDE.md

Pointer file for Claude Code / claude.ai agents.

This repository contains open-source [Agent Skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) for the [`ostr.io`](https://ostr.io) service catalogue.

When working in this repository, follow [`AGENTS.md`](AGENTS.md) and the skill files under [`skills/`](skills/).

When invoking a skill from a user's project, read the corresponding `skills/<name>/SKILL.md` from this repository and follow it end-to-end.

Available skills:

- `ostrio-prerendering` → [`skills/ostrio-prerendering/SKILL.md`](skills/ostrio-prerendering/SKILL.md)
